# UM-08 権限横断の受入確認

**目的:** 個別チケットをつないだ状態で、権限漏れと移行後の不具合を確認する。

**依存:** UM-02〜07

## 作業

- [改修要件](README.md)の権限表を画面・APIの両方で照合する。全ルートと全ナビゲーション項目を棚卸しし、暗黙に全ロール許可となった業務操作がないか確認する。
- 閲覧者のExcel・CSV出力、元ファイル・ZIPダウンロード、編集者以上の再照合、特権管理者のみのAmazon手動取込を通しで確認する。
- 既存ユーザーの移行、最後の特権管理者の保護、ロール変更後の複数セッション即時失効を確認する。
- 権限外の直URL・直接APIアクセス、削除済みユーザーのセッション、保存期限切れファイルの扱いを確認する。
- 既存テストを含む `composer test`、`npm run check`、`npm run build` と `git diff --check` を実行し、結果を記録する。

## 完了条件

- 要件の権限表と実装に相違がない。権限不足の操作によるデータ変更がない。
- 既存機能の回帰がなく、全チェックが通る。残る制約があれば実施結果に具体的に記録する。
