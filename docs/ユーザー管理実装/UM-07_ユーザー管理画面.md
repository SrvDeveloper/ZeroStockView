# UM-07 ユーザー管理画面

**目的:** 特権管理者がユーザーとロールを画面から管理できるようにする。

**依存:** UM-03、UM-04

## 作業

- ユーザー一覧、新規作成、編集、削除確認を実装する。扱う項目はログインID、パスワード、ロールだけにする。
- 新規作成では初期パスワードを必須とし、編集では空欄なら変更しない。確認入力とAPIの検証エラーを分かる形で表示する。
- 自分自身の削除と最後の特権管理者の削除・降格を、画面の案内とAPIエラーの両方で扱う。
- ロール変更後は対象ユーザーの全セッションが失効することを管理者に示す。自分のロールを変えた場合はログイン画面へ遷移する。
- 特権管理者メニューからのみ画面に進めるようにし、直URLはUM-04のガードで制御する。

## 対象の目安

`src/resources/js/pages/`、`src/resources/js/api/`、`src/resources/js/router/index.ts`、`src/resources/js/constants/navigation.ts`、関連するVitest。

## 完了条件

- 特権管理者が一覧・作成・編集・パスワード再設定・削除を完了できる。
- 入力エラー、最後の管理者の保護、権限変更に伴うセッション失効が画面から理解できる。
- 編集者・閲覧者にユーザー管理の導線がなく、直URLでも開けない。
