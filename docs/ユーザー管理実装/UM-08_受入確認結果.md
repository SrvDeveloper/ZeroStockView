## 権限表との照合

`README.md` の権限表を `src/routes/web.php`、画面ルート、ナビゲーション定義および権限テストと照合した。実行時の業務 API 31件は、全ロール8件、編集者以上9件、特権管理者のみ14件に分類され、暗黙に全ロールを許可する業務 API はない。ほかに共通アカウント API 2件、公開認証 API 2件、別の API キーで保護する外部在庫 API 1件がある。画面の保護対象ルート13件には明示的なロール指定があり、ナビゲーション8項目もロールが指定されている。

| 受入項目 | 確認結果 |
