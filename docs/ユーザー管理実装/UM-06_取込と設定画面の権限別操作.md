# UM-06 取込・品番グループ・管理画面の権限別操作

**目的:** 編集者が取込と品番グループ編集を使い、管理操作は特権管理者に限定する。

**依存:** UM-02、UM-04

## 作業

- データ取込画面は編集者以上に開放する。Amazon在庫の手動取込ボタンと実行導線は特権管理者だけに表示する。
- 品番グループ一覧・編集画面は編集者以上に開放し、削除ボタンと確認ダイアログは特権管理者だけに表示する。
- ファイル管理画面とAPI連携設定画面は特権管理者だけに表示する。元ファイルのダウンロードはUM-05の閲覧画面から全ロールに提供する。
- 連携ステータスの表示・更新を編集者以上に限定し、閲覧者から不要な状態取得APIを呼ばない。
- 権限外の操作に対する既存画面・ストアの失敗処理を確認する。

## 対象の目安

`src/resources/js/pages/DataImportPage.vue`、`ImportSettingsListPage.vue`、`ImportSettingsPage.vue`、`FileManagementPage.vue`、`ApiConnectionSettingsPage.vue`、`src/resources/js/components/IntegrationStatus.vue`、関連するVitest。

## 完了条件

- 編集者は取込と品番グループの作成・編集を完了でき、削除・Amazon手動取込・管理画面には進めない。
- 特権管理者は従来の全操作を使える。
- 閲覧者が取込・品番グループ・連携ステータスのデータ取得を開始しない。
