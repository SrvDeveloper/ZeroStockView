# UM-01 ロールの保存と認証応答

**目的:** 既存ユーザーを維持したまま、3種類のロールを認証状態に載せる。

**依存:** なし

## 作業

- `users` にロールを保持するマイグレーションを追加する。保存値は `admin`、`editor`、`viewer` の固定値とし、既存ユーザーは特権管理者へ移行する。
- `User` モデルにロールの定数または同等の型付き表現を設け、シーダーとファクトリーを更新する。
- `/api/login` と `/api/user` のユーザー応答にロールを加える。パスワード情報は返さない。
- 未知のロールが権限を得ない方針を定める。初期管理者が必ず特権管理者として作られることを確認する。

## 対象の目安

`src/database/migrations/`、`src/database/seeders/DatabaseSeeder.php`、`src/database/factories/UserFactory.php`、`src/app/Models/User.php`、`src/app/Http/Controllers/Api/AuthController.php`、関連するFeatureテスト。

## 完了条件

- 既存ユーザーは移行後もログインでき、ロールは特権管理者になる。
- 新規ユーザーの3ロールが区別して保存・取得できる。
- ログイン応答と `/api/user` のロールがDBと一致し、秘密情報を含まない。
