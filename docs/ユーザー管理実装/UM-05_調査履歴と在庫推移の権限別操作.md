# UM-05 調査履歴・結果と在庫推移の権限別操作

**目的:** 全ロールが閲覧とファイル取得を使え、変更操作は許可ロールだけに見せる。

**依存:** UM-02、UM-04

## 作業

- 在庫調査履歴・調査結果で、閲覧者にも結果Excelの出力と元の取込ファイル・一括ZIPのダウンロード導線を提供する。ファイル管理画面へのアクセスは不要にする。
- ファイルがない、保存期限切れ、削除済みなどの場合はダウンロード不可を画面で分かるようにする。APIの既存エラーも適切に表示する。
- 在庫推移CSVの出力は閲覧者にも表示する。
- 調査履歴の削除、調査結果のメモ編集は特権管理者だけに表示する。閲覧者・編集者はメモ内容を読める。
- 「保存ファイルで再照合」は編集者以上に表示する。閲覧者からのAPI呼び出しはUM-02で拒否する。

## 対象の目安

`src/resources/js/pages/SurveyHistoryPage.vue`、`SurveyResultPage.vue`、`InventoryTrendPage.vue`、必要なAPIクライアント・部品、関連するVitest。

## 完了条件

- 閲覧者で履歴・結果・推移を閲覧し、Excel・CSV・元ファイル・一括ZIPを取得できる。
- 閲覧者に再照合・削除・メモ編集が表示されず、編集者には再照合だけが表示される。
- ダウンロードできないファイルに対して壊れた導線を出さない。
