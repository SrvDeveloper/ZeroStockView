# 操作マニュアル整備

操作マニュアル（`src/resources/js/pages/ManualPage.vue`）を、現在のシステムの機能に合わせて完成させるための計画とチケット。チケット番号は `MAN-xx` で管理する。

## 方針（2026-10-19 依頼者確認済み）

- 対象はシステム自体の操作説明。外部システム（BOSS・ターコイズ）からのファイル取得の手順は、文章の誤りを直すだけにする。
- 「よくある質問」は作らない（節ごと削除する）。
- 画面キャプチャは入れない。画像の枠も置かない。必要な箇所には依頼者が後から挿入する。外部システムの手順にある既存の画像は残す。
- ダウンロードしたファイルのリネームのヒントは削除する。取込ファイルの種類はファイルの中身（1 行目の見出し）で判別するため、名前を変える必要はない。
- 画面の名前・ボタン・表示文言は、現在の画面（コード）と一字一句合わせる。権限によって使えない操作は、その旨を書き添える（[ユーザー管理の要件](../ユーザー管理実装/README.md)の権限表に従う）。
- 既存の節 ID（`introduction`、`basic-operation-boss`、`basic-operation-ec`、`basic-operation-free`、`notes`）は変えない。後から画像を入れる場所や目次のリンクを保つため。

## チケット一覧

### MAN-01 構成の整理と既存部分の修正

- 目次を上の完成形の順に組み直す（未作成の節はチケットごとに足す）。「よくある質問」を削除する。
- 外部システムの 3 手順の誤りを直す。手順の見出しの写し間違い（例: フリー在庫の手順の「ECストック倉庫のKEEP一覧表を出力」）、画像の説明文の写し間違い、節の見出しの表記を揃える。リネームのヒント 3 か所を削除する。
- 「はじめに」を書き直す。システムの概要（何を調べるシステムか）、1日の流れ（ファイル準備 → データ取込 → 結果の確認、Amazon在庫は毎朝自動取得）、権限ごとにできることの表、品番を CrossWalker に事前登録しておくこと。

**実装状況（2026-10-20）:** 実装済み。外部システムの手順で直したのは、フリー在庫の手順 2・3 の見出し（KEEP一覧表の写し間違い）と、画像の説明文 3 か所（02-2・03-3・04-3）だけ。それ以外の文言は元のまま残した。「Amazon在庫取得」と「注意事項」は、MAN-02・MAN-05 で書き直すまで、内容を変えずに置き場所だけ移した。

### MAN-02 データ取込と Amazon 在庫の取得

- データ取込: 3 種類のファイルの添付（1〜3 件、種類は中身で判別）、取込の実行、同じ日の追加取込で同じ調査が更新されること、未添付の種類は取込待ちになること、取込対象は全品番グループの品番であること。編集者以上の操作であること。
- Amazon在庫の取得: 毎朝 9:00 の自動取得、データ取込画面での状態と履歴の見方、手動取得（特権管理者のみ）、取得が成功するとその日の調査に反映されること（調査がなければ Amazon 在庫だけの調査が作られる）、取込待ち・一部SKU未取得の意味。

**実装状況（2026-10-20）:** 実装済み。「データ取込」の節を新設し、「Amazon在庫取得」の節を「Amazon在庫の取得」に書き直した。Amazon在庫の取り直しは同じ日のうちに行う必要があること（翌日の取得は前の日の調査に反映されない）も書き添えた。

### MAN-03 在庫調査履歴と在庫調査結果

- 在庫調査履歴: カレンダーとリストの切り替え、日の選択と詳細欄（取込ファイルの状態とダウンロード、一括ダウンロード、結果を開く、Excel出力）、削除（特権管理者のみ）。
- 在庫調査結果: 状態のまとめ、在庫表の見方（倉庫・総数・取込待ちの「—」・確定した「0」・全倉庫ゼロ／一部ゼロの表示、Ctrl＋マウスで内訳）、品番グループの切り替え、絞込、メモ（特権管理者のみ編集）、Excel出力（全件・絞込結果）、再読込、保存ファイルで再照合（編集者以上。使える場面と、旧方式の調査では使えないこと）、取込ファイルの一括ダウンロード。

**実装状況（2026-10-20）:** 実装済み。「在庫調査履歴」「在庫調査結果」の節を追加した。表示と意味の 2 列の表は共通部品 `ManualTermTable.vue` にまとめ、MAN-02 の Amazon の表もこれに置き換えた。あわせて、MAN-02 で「一部未取得の SKU は『—』」と書いていた誤りを「取込待ち」の札に直した。

### MAN-04 在庫推移

- 対象品番・在庫区分・表示期間・期間の選び方、品番全体（倉庫別の積み上げ、欠品SKU数、未確定の印、ツールチップ）と SKU別（ミニグラフ）、SKU別サマリーの見方、日次在庫のCSV出力（選択品番・全品番）。

**実装状況（2026-10-20）:** 実装済み。「在庫推移」の節を追加した。在庫区分と日次在庫CSVの列は表にまとめ、CSVの空欄（未確定）と 0 の違いをヒントとして書き添えた。

### MAN-05 設定画面と注意事項

- 品番グループ: 一覧、作成・編集（品番の検索と追加、並び順）、削除（特権管理者のみ）、取込対象は全グループの品番の和集合であること。
- ファイル管理（特権管理者のみ）: 保存期限（30日）、ダウンロード、削除。
- API連携設定（特権管理者のみ）: 外部APIの有効・無効、APIキーの再発行（表示は一度だけ）、許可するIPアドレス。
- ユーザー管理（特権管理者のみ）: 追加・編集・パスワード再設定・削除、権限変更でセッションが終了すること、最後の特権管理者の保護。
- 注意事項: 取込ファイルの保存期限、取込待ちと 0 の違い、Amazon在庫の反映のタイミング、旧方式（5ファイル）の調査の扱いなど、操作時に間違えやすい点。

**実装状況（2026-10-20）:** 実装済み。設定画面 4 節を追加し、注意事項のひな形を書き直した。注意事項には、チケットの項目に加えて、調査の日付（日本時間で取込を実行した日）と連携ステータスの見方を入れた。ユーザー管理の節には、全員が使える「パスワード変更」の場所も書き添えた。
