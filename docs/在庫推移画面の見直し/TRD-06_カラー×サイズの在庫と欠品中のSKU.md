# TRD-06 カラー×サイズの在庫と欠品中のSKU

**目的:** 詳細画面のヒートマップの下に、「カラー × サイズの在庫」と「欠品中のSKU」の2枚のカードを並べる。どのカラー・サイズが欠けていて、いつから欠品が続いているかを確かめられるようにする。

**依存:** TRD-05（`series[].color` を使う）

## 作業

- 2枚のカードを横に並べる（`repeat(auto-fit, minmax(420px, 1fr))`。狭い画面では縦に積む）。

### カラー × サイズの在庫

- 見出し「カラー × サイズの在庫（{最新の調査日}時点）」、説明「どのカラー・サイズが欠けているかを一目で確認します。小さい数字は1週間前との差です。」。
- 行がカラー（`series[].color` の出現順）、列がサイズ（SKU の `sort_order` に従った出現順）の表（`<table>`、行見出しは `<th scope="row">`）。右端に行の合計「計」。
- マスには最新の在庫数（Barlow Condensed 22px）と、その下に1週間前との差（「+3」「-5」「±0」。比べる日は TRD-04 と同じ関数）。
  - 欠品（確定した 0）のマスは淡い黄色（`#fff6d6`）に `#d9ad00` の内側の縁にし、差の代わりに「欠品 ◯日目」を出す。
  - 1〜4 のマスは縁を濃くする（墨 24%）。黄色は使わない。
  - 未確定は「—」。その組み合わせの SKU がないマスは空欄（斜線なし）にする。
- 合計に未確定を含む行は「計」を「—」にする。

### 欠品中のSKU

- 見出し「欠品中のSKU」、説明「欠品が続いている日数の長い順です。欠品が始まった日と、その前日の在庫を示します。」。
- 最新の調査日に欠品している SKU を、連続欠品日数の長い順に並べる。各行は、連続日数の札（「26 日目」）、SKU コードと「カラー 01 / XL」、「9/28（月）から欠品 · 前日の在庫 2」、右に「期間中 25 日」。
  - 連続日数と欠品の始まった日は、README の前提 4 と同じ規則（調査のない日で途切れない）で数える。期間より前から続いている場合は、期間の初日を始まりとして「◯日目以上」と出す（このチケットでは詳細 API を期間外まで広げない）。
- 欠品中の SKU がないときは「最新の調査で欠品しているSKUはありません。」を出す。

**実装状況（2026-10-23）:** ヒートマップのカードの下に、`InventoryColorSizeMatrix.vue`（カラー × サイズの在庫）と `InventoryStockoutList.vue`（欠品中のSKU）の2枚のカードを並べた。最新の調査日と1週間前の日は TRD-04 の `productMetrics` の値を使い、連続欠品は `utils/inventoryTrendMetrics.ts` の `stockoutStreak` で数える（一覧の集計 API と同じく、最後に在庫があった日の翌日から最新の調査日までの日数。未確定の日と調査のない日では途切れない）。チケットから決めた点は次のとおり。

- 欠品が始まった日は「最後に在庫があった日の後で、最初に欠品と確定した日」にした（README の前提 4）。在庫のあった日との間の調査のない日・未確定の日は欠品に数えない。そのため、デザインの「前日の在庫」は、欠品の前に最後に在庫があった日の在庫と日付を「直前の在庫 1（10/20（火））」の形で出し、カードの説明も「欠品が始まった日と、その直前の在庫（最後に在庫があった日）を示します。」にした（2026-10-23、依頼者の指摘で直した。最初は「最後に在庫があった日の翌日」を始まりにしていて、調査のない日と取込待ちの日まで欠品に数えていた）。
- 期間内に在庫のあった日がない SKU は、期間内で最初に欠品と確定した日を始まりとし（未確定の日は始まりにしない）、札を「◯日目以上」、説明を「{日付}から欠品 · 期間内にそれより前の在庫の記録なし」にした。カラー × サイズの表の欠品のマスも「欠品 ◯日目以上」と出す（2026-10-23、依頼者の指摘で、未確定の日から数えていた誤りと「期間の最初の調査」「それより前は期間外」の誤った文言を直した）。
- 欠品中のSKUの札（淡い黄色の四角に日数と「日目」の2段）と「期間中 ◯ 日」の2段の表示は、デザインに合わせた。
- カラー × サイズの表で、最新の調査日の調査に入っていない SKU（その日だけ調査にない）は、未確定と同じ「—」にした。カラー番号のない SKU は「カラーなし」、サイズのない SKU は「サイズなし」の行・列にまとめる。
- 1週間前と比べられないとき（比べる調査がない、どちらかが未確定）は、差を出さない。
