# 在庫推移画面の見直し計画

在庫推移画面を、品番を選んでから見る1画面の構成から、「品番一覧」→「品番の詳細」の2画面の構成に変える計画とチケット。

- デザイン確認用ページ: https://claude.ai/artifact/AFhK4n4cdJrSX78BAeqs4L（Version 3 で方針に合意、2026-10-23）
  - 「01 在庫推移（品番一覧）」と「02 品番の在庫推移（詳細）」の2枚。数値はすべてサンプル。
- チケット番号は `TRD-xx`（Trend）で管理する。

## 背景（依頼者の指摘、2026-10-23）

- 画面を開くと、いきなり特定の品番（1000）の在庫推移が出る。品番を選ぶ前に、全体を見渡せる一覧がほしい。
- SKU別の在庫推移（SKUごとの小さなグラフのカード）が見づらい。在庫推移を、もっと視覚的に分かるように見せたい。

## 作業範囲

**含む**

- 品番一覧画面の新設と、そのための集計 API（バックエンド）
- 在庫推移画面のルーティングを一覧（`/inventory-trends`）と詳細（`/inventory-trends/:productCode`）に分ける作業
- 詳細画面の作り直し（見出し、品番の数値、SKU別のヒートマップ、カラー×サイズの在庫、欠品中のSKU）
- 上記に伴う PHPUnit・Vitest の追加と更新、操作マニュアルと要件定義書の更新

**含まない**

- ブラウザでの表示確認。各チケットの完了後に依頼者が行う。チケットの完了条件は、自動チェックが通ることまでとする。
- 操作マニュアルの画面キャプチャの撮り直し（依頼者が表示確認とあわせて行う）。
- 日次在庫CSV・外部公開API（`GET /api/v1/inventory/daily`）の出力内容の変更。
- 倉庫別の積み上げ棒グラフ（`InventoryTrendChart.vue`）の描き方の変更。UIR-17・UIR-18 で作ったものをそのまま使う。

## 共通の完了条件

- `npm run check`（Prettier、ESLint、vue-tsc、Vitest）と `npm run build` が通る。
- バックエンドを変更した場合は、変更範囲の PHPUnit と `vendor/bin/pint --dirty --format agent` を実行する。
- 在庫数の `NULL`（取込待ち・未取得・データなし）を 0 として扱わない。未確定を含む合計は出さず「—」にする。欠品は「確定した 0」だけを数える。
- 在庫区分ごとの数量の決め方（ASIN のない SP-API 調査の SKU は Amazon を 0 とする、など）は、`InventoryTrendController::quantity()` と同じ規則にする。一覧と詳細と日次CSVで、同じ日の同じ品番の数値が食い違わないこと。
- API の応答は camelCase のキーにし、`resources/js/api/inventoryTrends.ts` の型を同時に更新する。
- 画面の文言は日本語で書く。

## デザイン仕様

色・書体・角丸は[画面デザイン刷新](../画面デザイン刷新/README.md)の「デザイン仕様」に従う。この計画で新しく使う表示は次のとおり。

### SKUの状況（一覧の各行）

- SKU 1つを 12px 四方・角丸 2px の四角で表し、2px の間隔で並べる（幅に収まらなければ折り返す）。並び順は SKU の `sort_order`。
- 在庫あり: `#7d8893`。欠品（確定した 0）: `#f5c400` に `#d9ad00` の内側の縁。未確定: 墨 35% の 45° 斜線に、墨 24% の内側の縁。
- 行の上に凡例（在庫あり・欠品（0）・未確定（—））を出す。四角の並び全体に `role="img"` と「◯SKUのうち欠品 ◯、未確定 ◯」の `aria-label` を付ける。

### SKU別のヒートマップ（詳細）

- 1行が1SKU、1マスが1日。行はカラーごとにまとめ、カラーの見出し行を挟む。
- マスの色は在庫数の段階で、墨の一色を淡い→濃いの順に使う。

| 在庫数 | 色 |
| --- | --- |
| 0（欠品） | `#f5c400`（内側の縁 `#d9ad00`） |
| 1〜4 | `#e2e6ea` |
| 5〜9 | `#c9d0d6` |
| 10〜19 | `#a8b1b9` |
| 20〜39 | `#7d8893` |
| 40 以上 | `#3a434c` |
| 未確定 | SKUの状況と同じ斜線 |
| 調査なし | 塗らない（墨 12% の内側の縁だけ） |

- 段階の区切りは固定値とする（品番ごとに変えると、品番を移ったときに色の意味が変わるため）。
- マスの高さは 20px、間隔は 2px。日付の見出しは期間が 31日以内なら1日おき、それを超えるときは間引く。土曜・日曜の日付はカレンダーと同じ曜日色にする。

### 品番の数値（一覧の上部・詳細の上部）

- 白いカードを4つ並べ、ラベル（11.5px）、数値（Barlow Condensed 34px・600）と単位、補足（11.5px・弱い文字）の3段にする。欠品に関わるカードは、数値の右に黄色の小さな四角を付ける。
- 画面幅が狭いときは折り返す（`repeat(auto-fit, minmax(220px, 1fr))`）。
