# UIR-13 ファイル管理画面

**目的:** ファイル管理画面（`FileManagementPage.vue`）を新デザインにし、保存期限までの残り日数を見えるようにする。

**依存:** UIR-04, UIR-05

## 作業

- 説明文（30 日で自動削除、調査結果とメモは残る）の下に要約を出す。保存中のファイル数、合計サイズ、期限まで 7 日以内の件数。
- 調査ごとのカード。
  - 見出しは在庫基準日時（等幅）。
  - 右に「一括ダウンロード」と「一括削除」（危険ボタン）。
- ファイルの行の列は、種類の札（角丸 4px、墨 6% の地）、ファイル名（等幅、長い場合は省略）、アップロード日時とサイズ（等幅・弱い文字）、残り日数、操作（ダウンロード、削除のアイコンボタン）。
- 残り日数は、幅 56px のメーターと「残り n 日」で示す。期限まで 7 日以内なら、注意のランプとメーターの注意色を付ける。
  - 残り日数は `uploadedAt` と、UIR-07 で `constants/` に移した保存期限（30 日）から計算する。Asia/Tokyo で日単位に切り上げる。
- ファイルがすべて期限切れの調査は、補助面の地に「保存期限を過ぎたため、ファイルは削除されました。調査結果とメモは残っています。」と出す。
- 削除・一括削除の確認モーダルは既存のものを使う。

## 対象ファイル

- `src/resources/js/pages/FileManagementPage.vue`
- `src/resources/js/pages/FileManagementPage.test.ts`（新規）

  - 注意表示の条件
