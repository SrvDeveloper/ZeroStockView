# 画面デザイン刷新計画

ZeroStockView の画面を、デザイン確認で合意した「B案 改（システム寄り・ライト）」に置き換えるための計画とチケット。

- デザイン確認用ページ: https://claude.ai/artifact/1XojG6Aea5q8vWoTA2tYCH（Version 7 で合意）
- チケット番号は `UIR-xx`（UI Renewal）で管理する。

## 作業範囲

**含む**

- フロントエンド（`src/resources/js`、`src/resources/css`、`src/resources/views/app.blade.php`、`src/vite.config.js`）の見た目と画面構成の変更
- 見た目の変更に伴う Vitest の更新と追加
- 任意チケット（`UIR-16`、`UIR-17`）を実施する場合のバックエンド変更と PHPUnit

**含まない**

- ブラウザでの表示確認。各チケットの完了後に依頼者が行う。チケットの完了条件は、自動チェック（`npm run check`、`npm run build` など）が通ることまでとする。
- 操作マニュアル（`ManualPage`）に載せる画面キャプチャの撮り直し。ブラウザ操作が必要なため、表示確認とあわせて依頼者が行う。
- 画面の機能追加。ただし、デザインに必要で、既存データから計算できる表示（前回比、全倉庫ゼロの件数、保存期限の残り日数など）は含む。

## 共通の完了条件

- `npm run check`（Prettier、ESLint、vue-tsc、Vitest）が通る。
- `npm run build` が通る。
- バックエンドを変更した場合は、変更範囲の PHPUnit と `vendor/bin/pint --dirty --format agent` を実行する。
- 既存の `data-testid` は削除・改名しない。画面の文言は日本語で書く。
- 在庫数の `NULL`（取込待ち・未取得）を 0 として扱わない。CLAUDE.md の Amazon 在庫の規則に従う。

## デザイン仕様

チケットから参照する値。トークン名は `UIR-01` で `@theme` に定義するものを示す。

### 色

| 用途 | 値 | トークン（案） |
| --- | --- | --- |
| 墨（文字・主ボタン） | `#11161a` | `--color-ink` |
| 本文の補助文字 | `#3a434c` | `--color-ink-2` |
| 弱い文字 | `#66717c` | `--color-muted` |
| さらに弱い文字 | `#a8b1b9` | `--color-faint` |
| 地（スチールグレー） | `#e8ebee` | `--color-canvas` |
| 面（カード） | `#ffffff` | `--color-surface` |
| 面（補助） | `#f5f7f8` | `--color-surface-2` |
| 罫線 | `rgb(17 22 26 / 0.09)` | `--color-line` |
| 罫線（弱） | `rgb(17 22 26 / 0.06)` | `--color-line-2` |
| 入力欄・ボタンの枠 | `rgb(17 22 26 / 0.15)` | `--color-line-strong` |
| 点線・空枠 | `rgb(17 22 26 / 0.24)` | `--color-line-stronger` |
| 信号の黄（在庫ゼロ専用） | `#f5c400` | `--color-signal` |
| エラー | `#c0362c`（背景 `#fdeeec`） | `--color-danger`、`--color-danger-soft` |
| ランプ 正常／注意／異常 | `#1f9d55`／`#d99e00`／`#d23a2f` | `--color-lamp-ok` など |
| サイドバー | `#161b20` → `#0e1215` の縦グラデーション、文字 `#a3acb5` | `--color-sidebar-*` |
| 倉庫色 Amazon／BOSS／フリー在庫／ECストック | `#3a6fb8`／`#e08a2e`／`#8e5bb8`／`#5f9e3a` | `--color-wh-amazon` など |

- 倉庫色は、この並び順のとき隣り合う 2 色が色覚の違いでも見分けられることを確認済み。積み上げは必ずこの順にする。BOSS の橙は白地でのコントラストが 3:1 未満なので、凡例と数値を必ず添える。
- 黄色は在庫ゼロに関わる表示、ナビの選択位置、ロゴだけに使う。
- 在庫ゼロの表示は 2 段階。1 倉庫だけの 0 は淡い縞（`#fff4c4`／`#ffe98f`）の札、全倉庫ゼロの行は行全体を `#fff6d6`（総数セル `#fff0c0`、0 の札 `#ffe27a`）にし、左端に黄黒斜線の帯を立てる。
- 検索に一致した行は `#eef3f7` にし、左端に墨の細い帯を立てる。
- カレンダーの曜日色は、日曜 `#b4483f`、土曜 `#44679e`。

### 黄黒斜線・方眼

- 斜線: `repeating-linear-gradient(-45deg, #f5c400 0 7px, #11161a 7px 14px)`。使う場所は、サイドバー上端（高さ 4px）、状態のまとめの「全倉庫ゼロ」カード下端（5px）、全倉庫ゼロ行の左端の帯（幅 5px）、ログインパネル上端（6px）。
- 方眼: `rgb(17 22 26 / 0.045)` の 1px の線。アプリ全体は 28px 間隔、ログイン画面は 32px 間隔。

### 書体と文字サイズ

| 用途 | 書体 | 例 |
| --- | --- | --- |
| 本文・見出し | Noto Sans JP（400／500／600／700／800）。`font-feature-settings: "palt" 1` をページ全体にかける | 画面タイトル（h1）22px・800・字間 0.04em、カード見出し 13.5px・600、本文 12.5〜13px |

### レイアウト

- サイドバー幅 212px。グループは「調査」「設定」「ヘルプ」。項目はアイコンと日本語名だけ。選択中の項目は半透明の白い面にし、左端に黄色の目印を付け、アイコンも黄色にする。
- 上部バーは高さ 44px で、`rgb(255 255 255 / 0.7)` に背景ぼかし 10px。左に現在地、右に時刻とアカウント。
- 本文の余白は上 22px・左右 28px。カードの間隔は 16px。
- 主ボタンは `linear-gradient(180deg, #2c333a, #12171b)` に、上端のハイライトを付ける。主ボタンは 1 画面に 1 つまで。
