# UIR-18 在庫推移画面をデザイン案に合わせる

**目的:** UIR-11 で既存の構成のまま残した在庫推移画面を、デザイン確認用ページ（Version 7）の「在庫推移」のモックに合わせる。データの取り方と集計は変えない。

**依存:** UIR-11, UIR-17

**経緯:** UIR-11 のチケットにはデザイン案どおりの作業が書かれていたが、実装では表示期間のセレクト、欠品 SKU 数の折れ線、SKU ごとの色を残し、棒の角丸・隙間や日付の目盛りも直していなかった。依頼者の確認（2026-10-19）で、デザイン案との違いが大きいと指摘された。

## 決定事項（2026-10-19、依頼者確認済み）

| # | 論点 | 決定 |
| --- | --- | --- |
| 1 | CSV 出力ボタン（デザイン案は 1 つ、現状は「選択品番」「全品番」の 2 つ） | 「日次在庫をCSV出力」1 つにまとめ、押すと「選択品番」「全品番」を選ぶメニューを出す |
| 2 | 表示期間の選択肢 | デザイン案どおり「2週間／1か月／3か月／期間指定」の 4 つ。1 年は「期間指定」で選ぶ |
| 3 | SKU別の表示（デザイン案に描かれていない） | 今のミニグラフのカード一覧を残し、墨の線・淡い面・終点の丸にする（最新が 0 なら黄色の丸に墨の縁）。SKU ごとの色はやめる |

## 作業

### タイトル行・条件のカード

- タイトル行の右は「日次在庫をCSV出力」（主ボタン）1 つにする。押すと「選択品番の日次CSV」「全品番の日次CSV」のメニューを出す。CSV の注意書き（「Amazon取得だけの日は他の在庫区分が空欄です」）はメニュー内に移す。
- 条件のカードは 1 行の 4 列（対象品番・在庫区分・表示期間・期間）にする。
  - 対象品番: 「MN-24A118 ・ ブランド ・ カテゴリ」の欄と「変更」ボタン。
  - 表示期間: `SegmentedControl`（2週間／1か月／3か月／期間指定）。
  - 期間: 開始日と終了日を、等幅の 1 つの欄の中に「→」でつないで並べる。日付を変えたら表示期間は「期間指定」になる。最大 365 日の制限は残し、注意書きの行は消す（制限は入力の min/max で守る）。
- 「この区分は調査日の保存済み在庫を合算します…」の注意書きは、グラフのカードの説明文に移す（モール全体・総数のときだけ）。

### グラフのカード（品番全体）

- 見出しは「{品番} の倉庫別在庫」、説明は「各日の最後の調査結果を集計しています。棒にマウスを置くと内訳を表示します。」にする。
- 見出しの右は「品番全体」「SKU別」の `SegmentedControl`（品番全体が先）。「再読込」はその左の小さいゴーストボタンにする。
- 凡例は 4 倉庫（在庫区分に含まれる倉庫）と「欠品SKU数」（黄色の四角）。未確定の日があるときだけ「未確定」を足す（UIR-17）。
- `InventoryTrendChart.vue`（棒グラフ）
  - 棒の幅は 1 日の間隔の半分。倉庫の間は 2px の隙間にし、いちばん上の段だけ上端を 3px の角丸にする。
  - 目盛り線は点線（墨 12%）、基準線は墨 35%。軸の文字は等幅 10px。
  - 日付の目盛りは、期間が 31 日以内なら毎日出す（初日と月が変わる日は `MM-DD`、ほかは `DD`）。31 日を超えるときは間引く。
  - 欠品 SKU 数は、右側の目盛りと折れ線をやめ、日付の下の「欠品」の行に、黄色の小さな四角と件数で出す（0 件の日は出さない）。
  - マウスを置いた日の列を薄く塗る（墨 5%）。ツールチップは倉庫別の内訳と合計（UIR-17 の未確定表示を含む）に、欠品 SKU 数と欠品 SKU の一覧を続ける。
  - 未確定の日の斜線の印（UIR-17）は残す。

### SKU別の表示・SKU別サマリー

- SKU別のカード一覧は残し、`InventoryTrendMiniChart.vue` を墨の線・淡い面・終点の丸にする。最新の値が 0 なら終点を黄色の丸（墨の縁）にする。`SERIES_COLORS` と SKU ごとの色の点は削除する。
- SKU別サマリーの表に「推移」列（墨の小さな折れ線、上と同じ終点の規則）を、SKU の右に足す。欠品日数が 1 以上なら黄色の札にする。

## 変えないこと

- API、集計、`NULL`（取込待ち・未取得）の扱い、在庫区分の選択肢と名前。
- 既存の `data-testid`（`period-select`、`trend-view-sku`、`trend-view-product`、`inventory-trend-export`、`inventory-trend-export-all`、`refresh-trend`、`product-chart-legend`、`sku-chart-grid`、`sku-summary-table`、`survey-scope-note` など）。付ける要素が変わる場合も、名前は残す。

## 完了条件

- Vitest で次を確認する。
  - 表示期間の 4 つの切り替えと、日付を変えたときに「期間指定」になること。
  - CSV のメニューから「選択品番」「全品番」を出力できること。
  - 欠品 SKU 数が日付の下に件数で出て、0 件の日は出ないこと。
  - 31 日以内は毎日の目盛りが出ること。
  - ミニグラフの終点（最新 0 なら黄色）。
- `npm run check` と `npm run build` が通る。

**実装状況（2026-10-19）:** チケットの作業をすべて実装した。`InventoryTrendChart.vue` は品番全体の積み上げ棒専用に作り直し、使われていなかった折れ線表示、SKU ごとの割合のツールチップ、欠品 SKU 数の右側の目盛りと折れ線を削除した。欠品 SKU の一覧と期間累計の欠品日数は、棒（日の列全体）にマウスを置いたときのツールチップに出す。棒の幅は日の間隔の半分（最大 32px）で、幅が 6px 未満のときは倉庫の間の隙間を付けない。欠品の件数の数字は、日の間隔が 18px 未満のときは省き、黄色の四角だけにする。`InventoryTrendMiniChart.vue` に表の「推移」列用の `variant="spark"` を足した。テストの data 属性はカードにだけ付ける。合算区分の注意書き（`survey-scope-note`）は、グラフのカードの本文の先頭に移した。テストは `InventoryTrendPage.test.ts`、`InventoryTrendChart.test.ts`、`InventoryTrendMiniChart.test.ts` を、新しい表示に合わせて書き直した。
